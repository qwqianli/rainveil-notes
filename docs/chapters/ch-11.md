# 2.8 复乐园

> 典出：弥尔顿《复乐园》
>
> 弥尔顿 1671 年《复乐园》写的是基督在旷野中三次拒绝撒旦的诱惑——不是夺回乐园，而是拒绝一条更快的路。这个标题用在南极篇，指向的是「抵达」与「诱惑」之间的选择，也是 2.0 系列的终章。

## 这一章的位置

南极篇，2.0 系列的终章，也是最冷的一章。标题来自弥尔顿——不是夺回乐园，而是三次拒绝一条更快的路。冰川、信鸽、故人的足迹。

## 画面与线索

- 一群信鸽穿过寒冷，替人送信
- 向前、向前，像手术刀一样割开冰川
- 公路与铁轨到不了的地方，应该有爪印
- 幕外三次驻足：是留下，还是迈出
- 海潮向鸟儿伸出手掌，它们终于飞起来
