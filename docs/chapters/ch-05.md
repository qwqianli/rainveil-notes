# 老虎的金黄

> 典出：博尔赫斯诗集《老虎的金黄》
>
> 博尔赫斯 1972 年诗集 El oro de los tigres。晚年失明的博尔赫斯反复书写老虎——那种他再看不见、却记得最清楚的金色。以此命名「第一防线学校」与编外小队的一段，暗示的是「记忆中的强度胜过眼前的现实」。

## 这一章的位置

一章关于「表决」。标题来自博尔赫斯晚年的诗集——他失明之后反复书写老虎，那种再也看不见、却记得最清楚的金色。一边是长桌上的计票，一边是棋盘上的落子，两件事做的是同一件。

## 画面与线索

- 一张不对等的长桌，和一份《探访须知》
- 隔着藤与叶，人们才想起她从哪里来
- 六次表决：反对、赞成、反对、中立、再反对
- 黑子靠、白子扳、黑子反扳——十步之内才见胜负
- 洪水将至，已经有人在挑自己的船筏
