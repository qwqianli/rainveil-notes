# 2.2 忧郁的热带

> 典出：列维-斯特劳斯《忧郁的热带》
>
> 列维-斯特劳斯 1955 年的人类学著作，写他深入巴西内陆考察却目睹「原始」被文明吞没的过程。书名本身就带着矛盾：热带并不忧郁，是观察者的位置让它忧郁。本章把舞台移到拉丁美洲，延续的正是这个「外来者凝视」的视角问题。

## 这一章的位置

拉丁美洲篇的入口，2.0 系列的第一章。标题来自列维-斯特劳斯的人类学著作——热带并不忧郁，是观察者的位置让它忧郁。一次行刑、一次重逢、一座封着东西的塔。

## 画面与线索

- 行刑队已经就位
- 每一次离别都可能是永别
- 一座塔，封条陈旧，有人对它很好奇
- 圣保罗的夜里，有人提议交个新朋友
- 恶战之后，大雨滂沱
