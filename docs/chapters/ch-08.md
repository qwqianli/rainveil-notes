# 1.9 孤独之歌

> **Vereinsamt** 是德语「孤独的、被遗弃的」。尼采 1884 年这首诗以乌鸦尖叫着飞向城市开头，写的是先知式的孤独：看清了真相的人，既回不去人群，也无处可去。
>
> 这是 1.0 系列的终章，也是公认的叙事高点。它的问题不在文本，在于它是此后所有版本的参照系——每出一个新版本，玩家都会拿它来比。

## 这一章的位置

1.0 系列的终章，也是此后每个新版本都会被拿来比的那一章。标题是尼采的诗《Vereinsamt》——德语「孤独的、被遗弃的」，写的是看清真相的人既回不去人群、也无处可去。

## 画面与线索

- 三座城市，同一个倒计时
- 一座不会被雨淋到的岛，和一群相信数字的人
- 一条船上，最智慧的虚无主义者正在领航
- 有人把火种带回了人间，代价是手上会留下烧伤
- 实验品被记作消耗品，重复千百遍，永不停歇

## 这一章的写法

三个空间同时推进，倒计时二十四小时。三条线的推进方式是一致的：先给出一个明确的目标，再让这个目标在最后一刻变得不再重要。值得注意的不是他们放弃了什么，而是文本从不解释放弃的理由——只写放弃之后的动作。

本章最值得注意的不是那些宏大句子，而是藏在灾难叙事中间的日常段落——比如「休息时光」那条关于插座排队的抱怨。它做了整个章节里最难的一件事：让权威变回一个人。
