# 洞穴的囚徒

> 典出：柏拉图《理想国》第七卷·洞穴寓言
>
> 洞穴寓言里，囚徒把墙上的影子当作全部真实；走出洞穴的人回来讲述真相，反而会被视为疯子。本章把阿派朗学派「以数为真理」的信仰体系建在这个寓言上——岛民看见了影子，也看见了举火的人，然后选择审判他。

## 这一章的位置

一座不下雨的岛，一群相信数字的人。标题直接取自柏拉图《理想国》第七卷的洞穴寓言：把影子当作全部真实的人，和举着火把回来讲述的人，谁才是那个疯子。

## 画面与线索

- 一场雷雨里，有孩子拍打着电视机
- 每个海难幸存者都会从同一块滩涂上醒来
- 十二面体、正五边形，和一条能推出嫌犯的数列
- 有人闭眼走进迷宫，丝线断了
- 战斗机出现在这座岛的和平之上
