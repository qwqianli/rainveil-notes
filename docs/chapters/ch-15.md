# 4.0 应门者

> 典出：威尔士中世纪文本《安农的掠获》
>
> Pa gur yv y porthaur? 是古威尔士语「谁是守门人？」，出自《安农的掠获》（Preiddeu Annwfn）——亚瑟王与守门人 Glewlwyd 的问答式对话。整段的体裁就是「隔着一道门互相报名字与功绩」，这正好是 4.0 卡美洛篇的舞台结构。

## 这一章的位置

4.0 卡美洛篇，游戏当前版本。标题是古威尔士语「谁是守门人」，出自《安农的掠获》——亚瑟王与守门人的问答，全程隔着一道门互相报名字与功绩。这一章讲的不是传说本身，是传说如何被反复重演、又被借去装另一个人。

## 画面与线索

- 一场用硬纸板当石中剑的正式演出
- 「尔等共沐天泽，带回吾王答案」——归来的，已是歧路人
- 六条骑士条例，一句一句地发誓
- 新船换掉旧板，起起伏伏中生命解构又重组
- 空荡的座位，留给未受邀的客人
- 最后的骑士，向天空中不可知的敌人宣战
