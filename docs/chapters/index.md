# 章节总览

收录范围是**主线的全部「画面—文案」单元**。每一帧在游戏里对应一幅 CG，配一句点睛文案——这一层的内容天然是短句，适合逐句看。

活动章节（1.2 绿湖噩梦、1.8 再见，来亚什基、2.4 地球上最后的夜晚、2.7 宇宙组曲 1987 等）**暂未纳入**：它们不在主线 CG 图鉴里，数据来源与主线不同，需要单独核实是否存在成体系的条目。**在被证实之前先空着，不用占位数据凑齐。**

下面每一张卡是一个章节。标了版本号的，点进去能读；标「版本待核」的，表示这一章的 CG 已经录入，但**我们还不能确证它属于哪个版本**，所以先留空，不猜。

## 关于版本号的说明

右侧那些金色标签是**已经核实**的版本号。灰的是待核。

这不是数据缺漏，是刻意的：这个项目的原则之一是**不为了让表格好看而填一个可能错的数字**。一个错误的版本号会让人找不到对应的剧情，比空着伤害大得多。如果你能提供确切出处，欢迎补上。
