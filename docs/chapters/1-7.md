# 1.7 今夜星光灿烂

> **E lucevan le stelle**（星光灿烂）是普契尼歌剧《托斯卡》第三幕的咏叹调。卡瓦拉多西在行刑前得知自己被骗、爱人并未获救，他回忆起花园的香气和爱人的吻，然后写下诀别——歌剧史上最著名的一段「明知无用仍要唱完」。
>
> 这一章把舞台放在维也纳，把行刑写进剧本之内。歌剧、死亡、欺骗三条线，在《托斯卡》原作里本来就是缠在一起的。

## 这一章的写法

四十五帧，是全作单章信息量最大的一章。它的组织方式不是事件推进，而是**语体的反复错位**：一会儿是歌剧咏叹调的腔调，一会儿是医学报告（「内视镜」「手术后」），一会儿是报刊标题（「爆炸新闻」）。

真正的分界线在最后三帧：「星光灿烂」→「无枕的夜」→「无星的夜」→「告别」。标题里的光一路减到零，最后落到「她失去了自己」。

## 一个提醒

这一章里有大量需要具体剧情才能确认的解读。凡是这类条目，卡片上都会挂一个**「需剧情佐证」**的标记——那不是免责声明，是告诉你：这一条是我的推断，你可以不同意，也可以推翻它。
