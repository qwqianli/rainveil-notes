# 项目说明

**雨幕拾遗**是一个非营利的同人赏析集。它只做一件事：把《重返未来：1999》里那些值得停下来看一眼的句子单独拎出来，回答两个问题——

1. **这一句在说什么？**
2. **它为什么这样写，而不是那样写？**

## 它不是的东西

| 它不是 | 原因 |
|---|---|
| 剧情 wiki | 已有做得非常完整的同类项目（按章分幕、梳理剧情脉络），没必要重复 |
| 文字版剧情存档 | 完整转载会实质性替代原作，这是侵权的边界，不碰 |
| 素材站 | 不托管任何官方立绘、CG、音频文件。理由见[引用与出处](/about/copyright) |
| 攻略 | 不涉及配队、数值、抽卡 |

## 为什么以「句子」为单位

章节级的剧情概要已经有人做了，句子级的赏析还没有。而这两件事的门槛完全不同：前者要通读全章，后者只要对一句话有感觉。

这也决定了它的协作方式——**一个人可以只贡献一条**。不需要读完一章，不需要玩到某个版本，只要你在某句话上停过一下。

## 三条原则

**一、不搬运，只评论。**
每一帧原文引用控制在点睛文案本身（一到两句）。赏析文字是主体，引用是靶子。

**二、区分「文本可证」和「需要剧情」。**
一条赏析如果只依赖这句话和它的标题就能成立，标 `text`；如果需要剧情背景才能说通，标 `plot`，页面上会明确显示「需剧情佐证」。这不是免责声明，是把判断的依据交给你。

**三、不知道就空着。**
版本号、角色归属、剧情细节——拿不准的一律留空或标待核。**一个错误的版本号比一个空字段伤害大得多。**

## 项目的形状

```
docs/
├─ chapters/          章节页（一章一页，页内嵌帧列表）
├─ quotes.md          句子墙（全库检索）
├─ about/             说明与规范
└─ .vitepress/
   ├─ data/           ← 唯一数据源，改内容只改这里
   │  ├─ chapters.json   章节元数据 + 典故溯源
   │  ├─ cg.json         帧：编号 / 中英标题 / 点睛文案
   │  └─ notes.json      赏析：解读 / 手法 / 标签 / 依据
   └─ theme/
      └─ components/  三个 Vue 组件，把 JSON 渲染成页面
```

内容与呈现是分离的：**加一条赏析，只需要往 `notes.json` 里加一个键**，不需要碰任何组件代码。
