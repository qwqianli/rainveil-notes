# 雨幕拾遗 · rainveil-notes

《重返未来：1999》的句子级赏析库。以一「帧」为单位（一幅 CG + 一句点睛文案）收录游戏文案，
并为其中一部分撰写赏析——回答这句话在做什么、为什么这样写、判断依据是文本还是剧情。

## 这是什么 / 不是什么

| | |
|---|---|
| ✅ 句子级赏析库 | 逐帧收录文案，配手法、判断依据与标签；章节标题附典故考据 |
| ❌ 不是剧情 wiki | 不搬运剧情全文，不做章节概要与角色资料；读原文请进游戏或社区 wiki |
| ❌ 不是素材站 | 不托管任何官方图片、立绘、CG、音频；页面用排版而不是截图做视觉锚点 |
| ❌ 不是攻略站 | 不涉及数值、配队、养成；这些需求已有专门站点 |

## 本地运行

```bash
npm install
npm run dev      # 开发预览，http://localhost:5173
npm run build    # 构建，产物在 docs/.vitepress/dist
```

改过数据后建议跑一次 `npm run check`：它校验三个 JSON 的一致性（重复 id、悬空引用、
非法字段值都会被拦下并给出具体条目定位），有错时进程退出码非 0，可直接接入 CI。

## 内容在哪里

全部内容数据在 `docs/.vitepress/data/` 下的三个 JSON 里，**改内容只改它们，不需要碰任何组件**：

- `chapters.json` — 章节元信息与标题典故（含置信度分级）
- `cg.json` — 帧：一句点睛文案 + 中英标题 + 全局编号
- `notes.json` — 赏析：正文、手法、判断依据（text / plot）、标签

赏析的质量下限（判断必须标依据、禁止复述剧情充当赏析等）见站内「贡献指南」页。
